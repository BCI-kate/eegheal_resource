# EEGHeal HTTPS resources

This repository hosts HTTPS resources for EEGHeal Unity feedback.

- `eegheal_resource_manifest.json`: resource metadata read by the Python platform.
- `eegheal_images/`: PNG feedback images.
- `eegheal_audio/`: OGG feedback audio.

Keep every `resource_id` unique. All public resource URLs must use HTTPS.
